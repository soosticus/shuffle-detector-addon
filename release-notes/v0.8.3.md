## Changes

- Linux: the companion is now a Flatpak (`ShuffleDetector-Companion-v0.8.3-linux.flatpak`) instead of a tar.gz, so it no longer depends on your distribution's libraries. It can see your home folder, `/mnt` and `/media`; if WoW is installed elsewhere, see the README for the one-line `flatpak override`.
- The companion also looks for WoW in Lutris's default Battle.net folder (`~/Games/battlenet`).

## Notes

- Windows and macOS: this is the first release to try the companion's built-in updater. Start 0.8.2, accept the update prompt, and the app should close and reopen on 0.8.3 with these notes shown.
- Linux Flatpaks can't update themselves: the companion tells you when a new release exists, and you install the new `.flatpak` by hand.
