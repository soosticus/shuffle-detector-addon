## Prices now come from Auctionator

ShuffleDetector no longer scans the auction house itself. It now requires [Auctionator](https://www.curseforge.com/wow/addons/auctionator) and reads its prices directly.

**What to do:** install Auctionator, scan the auction house with it, then `/reload` (or log out) so the game saves the data, and the companion picks it up.

### Changed
- The companion reads Auctionator's saved prices; the realm with the freshest data is selected by default.
- The companion shows a warning with a CurseForge link if Auctionator is not installed for the selected client.
- Disenchant yields are read from Auctionator's own disenchant table (your observed disenchants still take priority once you have samples).

### Removed
- The ShuffleDetector auction house tab and `/shuffledetector scan`. Old scan data is cleared on load.

### Notes
- Auctionator keeps minimum prices only, so buying large quantities is assumed to cost the minimum price each.
- This is the first release where the companion can update itself; earlier versions cannot, so download this one manually.
