## Companion improvements

- Switching the selected WoW installation now switches the loaded characters, recorded recipes and auction prices too. The companion remembers your selected installation for startup and automatic refresh, rather than picking a newer file from an old beta installation.
- Installations with no SavedVariables or auction prices clear previous results instead of leaving stale data visible.
- **File > Manage character data...** lets you exclude stale characters and their recorded recipes from the companion. Exclusions are separate for each installation; recheck a character to restore it. This never edits or deletes WoW's SavedVariables.
- Opening a SavedVariables file from another discovered installation selects that client automatically. Client tooltips show the full installation path.

## Getting started

- Update the companion, select your current WoW client, then use **Manage character data...** if stale characters remain.
- If the installation is not listed, use **Addon > Choose WoW folder...** first. With multiple accounts in one installation, **File > Open SavedVariables...** lets you choose an account explicitly.
- This is companion-side cleanup, not permanent deletion of character records in the game. Shared item, vendor and disenchant observations remain installation-wide.
- The addon's in-game workflow is unchanged.
