## Fixes

- The companion's self-update no longer stops at "closed but never restarted". When the companion was started from its own folder (as Explorer and shortcuts do), the update could not swap the folders, so it gave up and you were asked again on every start.

## Notes

- 0.8.2 and 0.8.3 still have this bug. To update from them, start the companion from a different folder: open a command prompt, run `cd C:\`, then run the companion's exe by its full path, and accept the update prompt. Or download this release and replace your copy once.
- From 0.8.4 on, updating from Explorer or a shortcut works normally.
